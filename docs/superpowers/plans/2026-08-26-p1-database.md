# P1 Database Schema — Implementation Plan

> REQUIRED SUB-SKILL: superpowers:executing-plans. Eksekusi inline dengan checkpoint owner di akhir fase.

**Goal:** Schema v1 produksi penuh NotaKit (ERD + semua amendments) di atas Drift + sqlite3mc terenkripsi, dengan migration harness dan DAO tests.

**Architecture:** Tabel Drift dipisah per grup domain (file kecil), dikomposisi dalam satu `AppDatabase` (schemaVersion=1). Executor memakai pola tervalidasi spike (key→FK→WAL→probe). Uang integer minor unit; qty integer micro-unit; timestamp UTC epoch-millis via TypeConverter.

**Tech Stack:** drift 2.34.3 • drift_dev 2.34.0 (pin) • sqlite3 3.5.2/sqlite3mc • flutter_test + NativeDatabase (host bila tersedia, fallback emulator).

**Spec:** `docs/NOTAKIT_ERD.md` + delta terdokumentasi `docs/AI_DECISION_LOG.md` D-007b/D-021 + amendments owner.

## Global Constraints

- Lanjutkan semua aturan Global Constraints IMPLEMENTATION_PLAN.md induk.
- Semua penyimpangan dari ERD asli HARUS tercantum di D-021 (tidak ada perubahan senyap).
- Nama kolom uang: suffix `_minor`; nama kolom qty: suffix `_micro`.
- Konstanta skala hanya di `lib/core/units/quantity.dart` (dan money helper) — tanpa literal tersebar.

## File Structure

```
lib/core/units/quantity.dart        — quantityScale + konversi micro<->decimal string
lib/core/money/money.dart           — Money type ringkas (int minor) + policy placeholder P2
lib/core/time/utc.dart              — converter DateTime <-> epochMillisUtc untuk drift
lib/database/app_database.dart      — @DriftDatabase komposisi + executor + migration strategy
lib/database/tables/*.dart          — definisi tabel per domain (owner/master/pricing/sales/
                                      payments/inventory/purchases/returns/system)
test/database/app_database_test.dart— buka DB, FK ON, migrasi v1->v2 harness, daftar tabel
test/database/tables/*_test.dart    — CRUD + constraint per grup
integration_test/spike_*            — tetap sebagai regression enkripsi
docs/superpowers/plans/…            — file ini
```
