# P2 Core Domain — Implementation Plan

**Goal:** Pure-Dart domain rules terpusat dan teruji penuh: MoneyPolicy, Qty, PricingEngine, DiscountEngine, BusinessClock — tanpa dependensi UI/DB.

**Spec:** SRS FR-PRICE-001/FR-SALES-003, ERD §17, DESAIN §36 + D-008/D-011/D-012.

## Tasks

### Task P2-1: Qty value object
- `lib/core/domain/qty.dart`: wrapper int micro; fromString/toString, add/sub, scaled mul/div (half-up), convertToBase(factorMicro).
- Test round-trip & konversi dus→pcs.

### Task P2-2: MoneyPolicy (D-011)
- `lib/core/domain/money_policy.dart`:
  - `lineGrossMinor(qtyMicro, unitPriceMinor)` — half-up integer math.
  - `applyLineDiscount(gross, {percentBp, fixedMinor})` → net ≥ 0.
  - `orderLevelDiscount(subtotal, level1PercentBp, level2PercentBp, fixedMinor)` — rumus SRS dengan guard ≥0.
  - `computeSaleTotals(...)` — urutan: subtotal → diskon nota → service charge (bp atas base didiskon) → shipping → pajak bp atas base merchandise didiskon saja → pembulatan denominasi (round-down) → grand.
  - Output `SaleTotals` immutable lengkap (semua komponen minor).
- Test: contoh angka manual (termasuk pembulatan Rp500, guard negatif, interaksi pajak-diskon).

### Task P2-3: PricingEngine (FR-PRICE-001)
- `lib/core/domain/pricing_engine.dart`: resolusi prioritas customer override → tier/customer-type → wholesale → standard; validitas tanggal & min_qty; tie-break spesifisitas min_qty lalu validFrom terbaru.
- Input berupa dataclass ringan (bukan row drift) agar domain bebas infrastruktur.
- Test tiap level prioritas + kadaluarsa + qty break.

### Task P2-4: DiscountEngine
- Bagian dari money_policy (order-level) + helper diskon bertingkat per baris bila perlu — test formula SRS `(g×(1−d1))×(1−d2)−F`.

### Task P2-5: BusinessClock (D-012)
- `lib/core/domain/business_clock.dart`: offset menit zona Indonesia umum (WIB/WITA/WIT) + UTC fallback; `dayRangeUtc(DateTime anyInstant, offsetMinutes)` → awal/akhir hari bisnis dalam UTC millis untuk report harian.
- Test batas hari lintas zona.
