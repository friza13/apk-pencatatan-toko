## Model checkout (semua dalam 1 db.transaction)

1. Validasi item (stok cuk utk goods terlacak; harga > 0).
2. Nomor nota = prefix + sequence+1 (update BUSINESS.sequence di tx sama).
3. Insert SALE (status confirmed/paid/partially_paid/credit) + SALE_LINES
   snapshot lengkap (qty_micro, conversion_factor_micro, qty_base_micro,
   unit_name/unit_price/cost snapshots, line_total).
4. STOCK_MOVEMENTS `sale_out` per line goods terlacak (−qty_base_micro).
5. PAYMENT(s): direction=in purpose=sale_payment ke akun kas default +
   LEDGER_ENTRY debit.
6. RECEIVABLE bila due>0 (+status open).
7. ACTIVITY_LOG 'sale.created'.
8. Void: status=voided + movement balik (sales_return-like via adjustment_in
   bertanda ref sale? → gunakan tipe 'adjustment_in' note=Void <nomor>) +
   ledger credit pembalik + audit.
